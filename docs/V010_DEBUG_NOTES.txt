V0.9 / V0.10 notes
------------------
NAS browse no longer flattens the share on Connect. Artist list is
one scandir. Tracks on an artist folder with deep=1 still os.walk
up to 2000 files over FUSE — can hitch on a large share.

TOSLINK EQ: ffmpeg_eq_filter() skips bands under 0.05 dB. Flat EQ
adds no -af (good). Harman builds a 9-filter chain. ffmpeg 4.2.2
on the host has lowshelf / equalizer / highshelf.

DLNA: HTTPS is rejected in play_url before ffmpeg. SOAP actions
were filled in V0.10 (see docs/DLNA_RENDERER_DEBUG.txt).

Spotify Connect wrapper on main already has the idle-status and
Pulse-backend fixes from PR #2.


Hot-path changes in this branch
-------------------------------
- _optical_ended() uses list_tracks(probe=False) so a skip does
  not spawn N ffprobe children.
- GET /api/auth/status lists the library without probing. Bitrate
  / sample rate still come from GET /api/library.
- GET /api/now reuses hostname, RAM, and /data disk for 5 seconds
  instead of UDP + /proc + statvfs on every 1s poll.
